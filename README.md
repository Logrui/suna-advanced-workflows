## **Suna Kortix Advanced Workflows - Extension for Suna Kortix to enable native advanced workflows with Kortix Triggers, Agents, and Integrations. Experimental

- Last Updated: <!-- DATE_START -->2025-12-27<!-- DATE_END -->**

## **Features**

- (1) Enables Kortix workers to make calls directly to LLM providers and vice versa Agentic Workflows with Files, CLI, and Sandbox Support

- (2) Advanced Automations and Workflows with Agent to Agent Communications and Inbox Communications Systems. 

- (3) Permission Levels and native Request Permission Tool (WIP) 

- (4) Enabling Native Subagents for Kortix Workers (WIP)
